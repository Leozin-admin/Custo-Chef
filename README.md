# CustoChef

Breve descrição: SaaS de gestão de custos para restaurantes, com cálculo 
de margem, controle de estoque e comparação de fornecedores.

## Funcionalidades
- Gestão de ingredientes com histórico de preços
- Fichas técnicas e cálculo automático de custo por prato
- Sugestão automática de reajuste de preço (margem < 35%)
- Comparação de preços entre fornecedores
- Alertas de estoque baixo
- Relatórios agendados por email
- Planos Free/Pro/Enterprise com Stripe

## Tecnologias
- Backend: Node.js, Express, Prisma, PostgreSQL
- Frontend: [tecnologia que você usa]
- Pagamentos: Stripe
- Email: Resend
- Monitoramento de erros: Sentry
- Deploy: Vercel (frontend) + Render (backend) + Neon (banco)
